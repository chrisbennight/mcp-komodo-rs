# Get help

Use [GitHub issues](https://github.com/chrisbennight/mcp-komodo-rs/issues) for
questions, reproducible bugs, and feature requests. This project is maintained
by [chrisbennight](https://github.com/chrisbennight); support is best effort.

Start with the [quickstart troubleshooting](docs/quickstart.md#troubleshooting)
or [gateway connection checks](docs/gateway-setup.md#verify-the-connection).
For a report, include the source revision or image digest, Core version, MCP
client, operating system, access profile, expected result, and a minimal
reproduction using synthetic data. Describe configuration by variable name.

Do not post credentials, real environment or Compose contents, private host
inventories, or unredacted logs. For a suspected vulnerability, follow
[the security policy](SECURITY.md) instead of posting technical details publicly.

For a feature request, describe the task you need to complete and an example of
the desired result. Read the [contribution guide](CONTRIBUTING.md) before
starting a substantial change. There is no guaranteed response time.
